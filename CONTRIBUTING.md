Thank you for contributing to MicQuill!

**How to contribute**
- Review existing issues before opening a new one.
- Use the provided templates for clarity.
- Keep your PRs focused on a single change.

**How we respond**
We aim to review feedback within 48 hours on business days. If no response in a week, ping us in the comments.

**First-timer checklist**
- [ ] Updated the docs
- [ ] Added tests for the new feature
- [ ] Linted with your tool of choice
- [ ] Squashed all commits into a single commit
